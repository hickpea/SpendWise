# 💰 SpendWise

A smart finance tracker to help you manage expenses, savings, and budgeting with ease.

---

## 🛠️ Tech Stack
- Node.js | Express.js | MongoDB
- HTML/CSS | JavaScript
- Twilio (optional for notifications)

---

## 🚀 Features
- Track daily expenses and categorize them
- Set monthly budgets and savings goals
- Generate reports and summaries
- Secure authentication and user accounts
- (Optional) SMS/email alerts for overspending
